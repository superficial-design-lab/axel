# Axel — AI Particle System

Interactive particle-based AI visualization created for Axelera.

Axel is an experimental visual identity system that represents the artificial intelligence behind the Axelera ecosystem through dynamic particles, reactive motion, and immersive ambient states.

## Overview

This project contains a standalone HTML experience featuring:

- Interactive particle simulation
- Multiple visual states and transitions
- Ambient AI-inspired motion system
- Fully self-contained HTML bundle
- Lightweight deployment-ready architecture

Designed as a visual representation of:

- Artificial intelligence
- Digital consciousness
- Adaptive systems
- Conversational interfaces
- Future-facing financial technology

## Features

- Standalone `index.html` file
- No installation required
- Runs directly in browser
- Bundled assets and dependencies
- Responsive fullscreen experience
- GPU-friendly animation rendering
